# First ROS 2 Package

## Objective
Learn how to create and build a ROS 2 Python package.

## Concepts Learned
- ROS 2 package structure
- package.xml
- setup.py / setup.cfg (or pyproject.toml depending on the template)
- colcon build
- sourcing the workspace

## Commands Used

```bash
ros2 pkg create ...
colcon build
source install/setup.bash
```
